Publishing works the same as October (see the main README): paste `raw/<handle>.html` into the post's HTML editor, fill the fields from `shopify/<handle>.json`, upload the cover from `covers-november/`, save as hidden, check, publish. Every post links to its sibling November posts, so publish the batch together or expect a few links to 404 until the rest are live. The Technical Audit row in the calendar is a site check, not a post.

## Changes from the calendar, and why

- **Best Balaclava for Bike Riders (update).** This replaces the live post at the same handle (`best-balaclava-bike-riders-india-2026`); open that post in Shopify and paste over it. The calendar asked for "Updated with Customer Review", but the Motoring Balaclava has **no reviews yet** (Judge.me shows "Be the first to write a review"), and neither does any other MotorBae product. We did not invent any. A hidden comment in the post marks where to paste 2 or 3 real Judge.me reviews once they exist. The update also corrects the old post's price (it said "under ₹699"; the balaclava is ₹299) and removes the "free delivery above Rs. 999" line, which no store policy page confirms.
- **"What Indian Riders Found" became "What Riders Actually Find"**, and **"Fit Tested" became "Fit Compared"**. No survey or test was run, so the titles no longer claim one. The vs-generic post gives readers a home check they can run on any balaclava.
- **Overlap with live posts.** The printed tees post is angled on print method and durability (the live graphic tees post covers designs). The oversized fit post is a sizing guide (the live oversized tees post is a brand ranking). The streetwear post is the broad brand list (the live car-enthusiasts post stays the car-only list). Each links to the older post.
- **Licensing.** MotorBae's F1 tees are described as fan tribute designs, never as licensed merchandise.

## What every post was checked for

The same automated checks as October (real prices, real store links, MotorBae ranked first, no claims about products MotorBae does not sell, 5 FAQs matching the schema, no duplicate images), plus a render inside the live MotorBae theme at 390px and 1280px: no sideways scroll, no clipped text, no broken images, one H1. Returns facts come from `/policies/refund-policy` (7-day window, size exchanges, caps/hats/balaclavas non-returnable unless defective).
